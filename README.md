Wazuh SIEM + Windows Endpoint Monitoring

Tools: Wazuh, Sysmon, Windows Event Viewer, Ubuntu Server

Network Traffic Analysis — Zeek + Suricata
Set up Zeek on an Ubuntu VM, configured live capture between a Windows VM and the Zeek instance, and verified internal network traffic collection. Ran both training and malicious PCAPs through Zeek to compare normal vs suspicious activity. Used Suricata on the same malicious PCAP to compare signature-based detection with behaviour-based analysis. Identified infected hosts, suspicious DNS requests, malicious HTTP activity, and TLS connections to suspicious infrastructure.
Tools: Zeek, Suricata, zeek-cut, Wireshark

Tools: PEStudio, FLOSS, Detect It Easy, PowerShell
